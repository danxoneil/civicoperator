# How states define “rural”

Each state decides which communities count as “rural” for its Rural Health Transformation Program. This table records that choice for all 50 states — whether the state uses its **own definition**, a fixed **county list**, or the federal **HRSA/FORHP** default — alongside how rural the state is on a common federal baseline and a link to the state’s own source. **15 states publish an actual rural map** (gallery below); the rest define rural in text or defer to the federal standard. The *% rural* column is a single comparable yardstick — the share of the state’s counties (or census tracts) that are rural under the HRSA/FORHP standard — *not* the state’s own count, which often differs. It is a factual classification, not a ranking. See [Methodology](/work/rht/states/methodology) for how this is derived.
