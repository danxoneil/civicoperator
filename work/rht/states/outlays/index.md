# RHTP outlays by state

Every state runs its Rural Health Transformation Program on a federal cooperative agreement, and two numbers track the money: **obligated** — funds CMS has committed to the state — and **outlaid** — funds actually disbursed to date. This table records both for all 50 states, pulled weekly from USASpending.gov (federal program 93.798). As of 2026-11-22, states had drawn down **$347.1 million** of **$20.00 billion** obligated so far — about 1.7%. Obligated totals include the Year 1 award and any Year 2 continuation funding CMS has since added to the same agreement. Federal award pages report each state’s outlays one grant at a time; this is a maintained side-by-side comparison of all 50. See [Methodology](/work/rht/states/methodology) for sourcing.
