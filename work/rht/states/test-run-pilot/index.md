What is Test Run Pilot's Rural Health Transformation Program allocation, and how is the funding structured?

Test Run Pilot received approximately **$55M** in Year 1 Rural Health Transformation Program funding from CMS — its share of the federal $50 billion program. The exact award and five-year structure are set out in the state's CMS-approved project and budget narratives.

What legislation or state action enables Test Run Pilot's RHTP?

The Rural Health Transformation Program was created by **Section 71401 of the One Big Beautiful Bill Act (2025)** and is administered federally by CMS. Test Run Pilot administers its award through its state-designated agency under CMS-approved project and budget narratives.

How can vendors, providers, or consultants engage with Test Run Pilot's program?

Eligibility runs on two tracks. **Direct-to-state contracts** go out as competitive RFPs where firms bid as **prime contractors**; **subgrants and subawards** flow to rural providers — hospitals, Rural Health Clinics, FQHCs, Tribal health organizations, EMS agencies, counties and fire districts — where technology vendors and consultants most often engage as **subcontractors or implementation partners** rather than direct grantees.
