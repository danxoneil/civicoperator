# Markdown negotiation Worker

Implements the **Markdown Negotiation** ("Markdown for Agents") item from
Cloudflare's Agent Readiness rubric — without paying for Pro. It serves the
clean `.md` companion of a page to any agent that sends `Accept: text/markdown`,
while browsers keep getting HTML.

- **Code:** [`markdown-negotiation.js`](markdown-negotiation.js) — static; it never
  needs changing when site content changes.
- **Markdown source:** the `.md` files next to each page, generated by
  [`../scripts/generate_markdown.py`](../scripts/generate_markdown.py) and served
  by the GitHub Pages origin.

## One-time deploy (Cloudflare dashboard, ~3 minutes)

The Worker code is static, so this is done **once**:

1. Cloudflare dashboard → **Workers & Pages** → **Create application** →
   **Create Worker**. Name it e.g. `markdown-negotiation`. Click **Deploy**
   (the placeholder), then **Edit code**.
2. Replace the placeholder with the full contents of
   [`markdown-negotiation.js`](markdown-negotiation.js) → **Deploy**.
3. Attach it to the site: open the Worker → **Settings → Domains & Routes →
   Add → Route**:
   - Zone: `civicoperator.com`
   - Route: `www.civicoperator.com/*`
   - (optional) add a second route `civicoperator.com/*`

That's it. The DNS records are already proxied through Cloudflare, so the route
takes effect immediately.

## Verify

```bash
# Agent view -> Markdown
curl -s -H "Accept: text/markdown" https://www.civicoperator.com/ | head
curl -sI -H "Accept: text/markdown" https://www.civicoperator.com/ | grep -i "content-type\|x-markdown"

# Browser view -> still HTML, now advertising the alternate
curl -sI https://www.civicoperator.com/ | grep -i "content-type\|link"
```

You want: the first command returns Markdown with `Content-Type: text/markdown`
and `X-Markdown-Negotiation: hit`; the last shows `Content-Type: text/html` plus
a `Link: <…/index.md>; rel="alternate"; type="text/markdown"` header.

Then **Rescan** in Agent Readiness → Diagnostics; the Markdown Negotiation check
should pass.

## How it maps URLs to companions

| Requested URL | Companion served |
|---|---|
| `/` | `/index.md` |
| `/work/rht/states/texas/` | `/work/rht/states/texas/index.md` |
| `/monday-crm.html` | `/monday-crm.md` |
| `/work` (extensionless) | `/work/index.md` |
| `/css/site.css`, `/sitemap.xml`, `*.md` | *(passed through, not negotiated)* |
