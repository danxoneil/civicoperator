# robots.txt for civicoperator.com

# SELF-HOSTED (since 2026-09-14). Cloudflare's "Managed robots.txt" used to
# PREPEND a generated block above this file; that block could not express what
# this site actually wants, so it was turned off:
#
#   * it had no way to declare `ai-input=yes` (the content signal that permits
#     grounding / RAG — i.e. being CITED), and
#   * it hard-blocked `Google-Extended`, which is not merely a training control:
#     it also gates whether content may ground Gemini answers. Combined with
#     Google-CloudVertexBot having never once fetched this site, that left the
#     Gemini citation path with no data route at all.
#
# The whole point of this site's RHTP reference layer is to BE CITED by answer
# engines. See CLOUDFLARE_GEO_ROBOTS.md in the private civicoperator-geo repo
# for the citation-monitoring data behind these choices.
#
# Verify after deploy:  curl -s https://www.civicoperator.com/robots.txt
